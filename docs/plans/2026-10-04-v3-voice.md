# Voice recognition v3 implementation plan

**Spec:** `docs/specs/spec-v3-voice.md`. Executed inline, TDD. Tests: `assistant/tests/test_voice_v3.py` (+ existing suite stays green).

## Global constraints
- Open-set: unknown voices are never stored; `forget` removes samples. Embedding dim may change: never mix dims in one person.
- Scoring API stays `SpeakerEngine.identify(audio) -> Match` so the pipeline is unchanged except turn pooling (Task 3).

## Task 1: kNN scoring over per-source samples (R1)
- Samples carry `source` like `enrol:laptop`, `enrol:buds`, `adapt:buds`, `cluster`. `SpeakerEngine._samples: dict[pid, list[(emb, source)]]`.
- `person_score(e, pid)` = mean of top-3 cosines (best if < 3). `identify` and `score` use it; margin test uses these scores.
- Test: two synthetic "channels" of one voice (FakeEmbedder with channel offset) enrolled as 2 groups; a probe from either group scores
  >= threshold; old mean-centroid scored < threshold on the same probe (documents the bug). Test with the real DB embeddings (skip if absent):
  group-B vs group-A kNN beats mean-centroid by >= 0.10.
## Task 2: Score normalisation with a cohort (R2)
- `SpeakerEngine.cohort` list of embeddings (unknown cluster embeddings + persisted others + optional `cohort.npy`); `snorm(raw, e, pid)`.
- `identify` compares the **normalised** score to `threshold_z` when cohort >= 10, else raw to `threshold`. `Match.score` stays raw for display, `Match.z` added.
- Test: with cohort, an impostor with high raw similarity (0.70) but also high cohort similarity is rejected while the genuine probe is accepted.
## Task 3: Turn pooling (R3)
- `pipeline` groups consecutive segments (gap <= 1.5 s, raw cosine to previous turn embedding >= 0.35) into a turn; identity is the
  duration-weighted pooled embedding; short segments follow the rule in spec R3. Emits `probably_you` flag for the UI only.
- Test: scripted alternating speakers + one-word interjections -> <= 1 wrong label in 20 turns.
## Task 4: Safe adaptation + rollback (R4)
- `SpeakerEngine.adapt(pid, emb, source, quality)` gated (>= 2 s speech, high score, not inherited, cap 40/source); `forget_adapted(pid, since)`.
- Test: adaptation raises later score of a drifted-channel probe; never adapts on an impostor; rollback restores old scores; cap enforced.
## Task 5: Enrolment API: add to existing person, per-source clips, playback (R1)
- `POST /api/v2/voices/add` {person_id | name, source, wav_base64} -> adds chunks as samples with `enrol:<source>`; `GET /api/v2/voices/{pid}/health`.
- Test: adding to existing person does not create a duplicate; health returns per-source sample counts and a verdict.
## Task 6: Voice health + decision reasons (R5)
- `calibrate.health(engine, pid)`: per source genuine range (leave-one-out among samples), nearest impostor from cohort, verdict.
- Decision reasons for Unsure/Unknown stored in segment events (`why`).
## Task 7: Embedder benchmark (R6)
- `eval/voice_bench.py` runs EER on synthetic voices through candidate models if present; adds `speaker_model` config. Models that cannot be
  downloaded offline are reported as "not available"; keep ResNet34 as default unless a candidate is installed and wins by >= 15%.
